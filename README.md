# BitChord Internet Archive FLAC Add-on

Searches Internet Archive for audio items with actual `.flac` files and returns their direct URLs. It does not convert MP3/AAC/YouTube audio into lossless quality. Use it for public-domain or appropriately licensed audio.

## Deploy to Render
1. Upload these files to a new GitHub repository.
2. In Render, choose **New → Blueprint** and connect that repository, or create a Web Service using `render.yaml`.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn --bind 0.0.0.0:$PORT server:app`
5. After deployment, test `https://YOUR-SERVICE.onrender.com/manifest.json` and `/health`.
6. In BitChord → Sources → Add an addon, paste `https://YOUR-SERVICE.onrender.com/manifest.json`.

## Endpoints
- `GET /manifest.json`
- `GET /health`
- `GET /search?q=classical`
- `GET /stream/ITEM_IDENTIFIER`

A public HTTPS URL is generated by your hosting provider after you deploy; this archive does not itself include a live hosted service.
